# She Doesn't Sleep

A phone game set in an old house on Miller Road, Knox County, Ohio. Pick a survivor and the woman who hunts you, then escape in 3D or from a top-down map. Solo, a two-player room code, and a score list on the device.

Unofficial game. This is not Granny and is not connected to its author.

## Android APK

The installable build is made on GitHub, not on a phone. A tag `v*` (or the Android APK workflow) produces `She-Doesnt-Sleep.apk` and attaches it to a [release](https://github.com/LuntikVisuals/DomMishki/releases).

Solo play works offline after install. A two-player room still needs the website, because that server is not inside the APK.

## Запуск

```bash
npm install
npm run dev
```

Игра откроется на порту `8080`.
