# Дом Мишки

Браузерная игра: выживший прячется в доме, мишка в цилиндре охотится. Есть одиночная партия, комната на двоих по коду и локальная таблица рекордов.

Фан-трибьют. Мишка в цилиндре вдохновлён Фредди Фазбером. Все права на этого персонажа принадлежат Скотту Коутону (Scott Cawthon). Неофициальная игра, с автором не связана.

## Запуск

```bash
npm install
npm run dev
```

Игра откроется на порту `8080`.
